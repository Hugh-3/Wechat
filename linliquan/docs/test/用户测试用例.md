# 邻里圈小程序 - 用户测试用例

## 测试范围
- 目标用户：社区业主
- 测试平台：微信小程序
- 测试时间：待定
- 测试人员：5-10名社区业主

---

## 一、认证流程测试

### TC-001: 新用户首次登录
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户首次打开小程序 |
| 测试步骤 | 1. 点击"我的"页面<br>2. 输入手机号进行登录 |
| 预期结果 | 1. 系统自动创建用户账户<br>2. 用户状态为"未认证"<br>3. 只能浏览，不能发布 |
| 优先级 | P0 |

### TC-002: 提交业主认证申请
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户已完成登录，状态为"未认证" |
| 测试步骤 | 1. 进入"认证"页面<br>2. 上传身份证照片<br>3. 填写房号信息<br>4. 提交认证申请 |
| 预期结果 | 1. 系统提示"提交成功，等待审核"<br>2. 用户状态变为"认证中"<br>3. 仍然只能浏览 |
| 优先级 | P0 |

### TC-003: 认证通过后功能解锁
| 项目 | 内容 |
|------|------|
| 前置条件 | 后台管理员审核通过用户认证 |
| 测试步骤 | 1. 重新打开小程序<br>2. 查看认证状态 |
| 预期结果 | 1. 用户状态变为"已认证"<br>2. 可以发布动态<br>3. 可以发布互助任务 |
| 优先级 | P0 |

---

## 二、信息广场测试

### TC-101: 浏览信息广场帖子
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户已登录（任意状态） |
| 测试步骤 | 1. 进入"广场"页面<br>2. 向下滚动浏览帖子列表<br>3. 点击帖子查看详情 |
| 预期结果 | 1. 帖子列表正常加载<br>2. 显示发布者昵称和头像<br>3. 显示点赞数和评论数<br>4. 下拉刷新成功 |
| 优先级 | P0 |

### TC-102: 发布信息广场帖子
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户状态为"已认证" |
| 测试步骤 | 1. 点击发布按钮<br>2. 选择"信息广场"<br>3. 填写标题和内容<br>4. 上传图片（可选）<br>5. 点击发布 |
| 预期结果 | 1. 发布成功后返回广场页面<br>2. 新帖子显示在列表顶部<br>3. 提示"发布成功" |
| 优先级 | P0 |

### TC-103: 未认证用户发布被拦截
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户状态为"未认证"或"认证中" |
| 测试步骤 | 1. 点击发布按钮<br>2. 尝试发布内容 |
| 预期结果 | 弹出提示："仅认证业主可发布"或"认证审核中" |
| 优先级 | P0 |

### TC-104: 点赞帖子
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户状态为"已认证"，有可点赞帖子 |
| 测试步骤 | 1. 在帖子列表点击点赞按钮 |
| 预期结果 | 1. 点赞数+1<br>2. 按钮变为已点赞状态 |
| 优先级 | P1 |

## 三、邻里互助测试

### TC-201: 查看附近互助任务
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户已登录（任意状态） |
| 测试步骤 | 1. 进入"互助"页面<br>2. 允许位置授权<br>3. 查看附近任务列表 |
| 预期结果 | 1. 显示用户位置附近的互助任务<br>2. 按距离从近到远排序<br>3. 显示距离（如"约500米"）<br>4. 显示酬劳金额 |
| 优先级 | P0 |

### TC-205: 发布互助任务
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户状态为"已认证"，已开启位置权限 |
| 测试步骤 | 1. 点击发布按钮<br>2. 选择"邻里互助"<br>3. 选择互助类型（拼单/代买/求助/技能）<br>4. 填写任务信息<br>5. 设置酬劳（可选）<br>6. 发布 |
| 预期结果 | 1. 发布成功后显示在互助列表<br>2. 其他用户可以看到此任务 |
| 优先级 | P0 |

### TC-206: 接单互助任务
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户状态为"已认证"，有可接单任务 |
| 测试步骤 | 1. 在互助页面点击任务卡片<br>2. 点击"我来帮忙"按钮 |
| 预期结果 | 1. 任务状态变为"进行中"<br>2. 显示"已接单"标记<br>3. 创建者收到通知 |
| 优先级 | P0 |

### TC-207: 不能接自己发布的任务
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户有已发布的互助任务 |
| 测试步骤 | 1. 在互助页面找到自己发布的任务<br>2. 点击"我来帮忙" |
| 预期结果 | 提示"不能接自己的任务" |
| 优先级 | P1 |

## 四、权限与安全测试

### TC-301: Token过期处理
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户已登录，Token已过期 |
| 测试步骤 | 1. 等待Token过期（约24小时）<br>2. 尝试进行写操作 |
| 预期结果 | 弹出"登录已过期"提示，引导重新登录 |
| 优先级 | P0 |

### TC-302: 并发操作处理
| 项目 | 内容 |
|------|------|
| 前置条件 | 用户状态为"已认证" |
| 测试步骤 | 1. 快速连续点击发布按钮多次 |
| 预期结果 | 只发布一条帖子，不会重复发布 |
| 优先级 | P2 |
