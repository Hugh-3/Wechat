## 三、后端部署步骤

### 1. 数据库准备
```sql
-- 1. 创建数据库
CREATE DATABASE linliquan;

-- 2. 连接数据库并启用扩展
\c linliquan
CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- 3. 执行初始化脚本
\i /path/to/init.sql
```

### 2. 配置文件修改
修改 `application.yml` 中的配置：
```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/linliquan
    username: your_username
    password: your_password
  
  redis:
    host: localhost
    port: 6379
    password: your_redis_password

server:
  port: 8080

# JWT配置
jwt:
  secret: your_jwt_secret_key
  expiration: 86400000  # 24小时
```

### 3. 打包部署
```bash
# 进入后端目录
cd backend

# 打包
mvn clean package -DskipTests

# 运行
java -jar target/linliquan-1.0.1.jar

# 或使用nohup后台运行
nohup java -jar target/linliquan-1.0.1.jar > app.log 2>&1 &
```

### 4. Nginx配置（推荐）
```nginx
server {
    listen 80;
    server_name api.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 四、前端部署步骤

### 1. 修改API地址
修改 `src/utils/request.js` 中的API_BASE_URL：
```javascript
const API_BASE_URL = 'https://api.yourdomain.com';
```

### 2. 小程序配置
修改 `project.config.json`：
```json
{
  "appid": "your_appid",
  "projectname": "linliquan"
}
```

### 3. 上传代码
1. 打开微信开发者工具
2. 导入项目（frontend目录）
3. 点击"上传"按钮
4. 填写版本号和项目备注
5. 提交审核

### 4. 发布
1. 登录微信公众平台
2. 进入"版本管理"
3. 提交审核通过的版本
4. 点击"发布"

## 七、回滚方案

### 后端回滚
```bash
# 停止当前版本
kill <pid>

# 启动上一版本
nohup java -jar linliquan-1.0.0.jar > app.log 2>&1 &
```

### 数据库回滚
```bash
# 从备份恢复
pg_dump -U username linliquan > backup_before_update.sql
# 如需回滚
psql -U username linliquan < backup_before_update.sql
```

### 小程序回滚
1. 登录微信公众平台
2. 进入"版本管理"
3. 选择"回退到上一版本"

## 八、监控与运维

### 关键指标监控
- API响应时间
- 错误率
- 并发用户数
- 数据库连接数
- Redis命中率
- 服务器CPU/内存/磁盘

### 告警配置
- 错误率 > 5%
- 响应时间 > 3s
- CPU使用率 > 80%
- 内存使用率 > 85%
- 磁盘使用率 > 90%

### 备份策略
- 数据库：每日全量备份 + 每小时增量备份
- 备份保留：30天
- 备份存储：异地存储
