# 邻里圈 - 版本更新说明

## v1.3.0 (2026-07-02)

### ✨ 新增功能

#### 资料编辑
- 新增"编辑资料"页面，支持修改头像和昵称
- 头像上传支持从相册选择或拍照
- 昵称长度限制 20 个字符
- 保存后同步更新本地存储和页面显示

#### 帖子搜索
- 新增帖子搜索功能，支持按关键词搜索标题和内容
- 搜索结果支持按类型筛选（全部/信息广场/邻里互助）
- 搜索历史记录，最多保存 10 条，支持一键清空
- 广场页面 Tab 栏新增搜索入口图标

#### 获赞记录（接入真实接口）
- 获赞记录从模拟数据改为调用真实后端接口 `GET /v1/users/likes`
- 展示点赞人头像、昵称、帖子标题和点赞时间
- 支持分页加载和点击跳转帖子详情

#### 评论记录（接入真实接口）
- 评论记录从模拟数据改为调用真实后端接口 `GET /v1/users/comments`
- 展示帖子标题、评论内容和评论时间
- 支持分页加载和点击跳转帖子详情

#### 评论回复功能
- 帖子详情页评论支持回复功能（楼中楼）
- 点击"回复"显示回复提示条，支持取消回复
- 回复时携带 parentId 和 replyToUserId 参数

### 🔧 后端新增

#### 新增接口
- `PUT /v1/users/profile` - 更新用户资料（昵称、头像）
- `GET /v1/users/likes` - 获取用户获赞记录（分页）
- `GET /v1/users/comments` - 获取用户评论记录（分页）
- `GET /v1/posts/search` - 搜索帖子（关键词 + 类型筛选）

### ✅ 工程质量
- 所有"开发中"占位功能已全部实现，前端代码中不再有任何 `开发中` Toast
- 获赞记录和评论记录页面添加点击跳转绑定
- 评论 API 支持 parentId 和 replyToUserId 参数

## v1.2.0 (2026-07-02)

### ✨ 新增功能

#### 收藏功能
- 新增帖子收藏/取消收藏功能
- 新增"我的收藏"页面，展示用户收藏的帖子列表

#### 获赞记录页面
- 新增"获赞记录"页面，展示总获赞数和点赞记录
- 顶部统计卡片展示总获赞数

#### 评论记录页面
- 新增"评论记录"页面，展示总评论数和评论历史
- 顶部统计卡片展示总评论数

#### 订单详情联系功能
- 修复订单详情页"联系"按钮无响应的问题
- 支持在线客服咨询（`wx.openCustomerServiceConversation`）
- 支持拨打客服电话（`wx.makePhoneCall`）

### 🔧 工程质量改进

#### 页面配置补全
- 为 `index`、`helper`、`my-posts`、`my-orders`、`favorites`、`likes`、`comments` 页面补充 `index.json` 配置
- 开启 `enablePullDownRefresh` 使下拉刷新功能生效
- 统一导航栏标题文字

### 🔧 后端新增

#### 新增数据表
- `favorites` - 帖子收藏记录表

#### 新增接口
- `POST /v1/favorites/{postId}` - 收藏/取消收藏
- `GET /v1/favorites/my` - 获取我的收藏列表
- `GET /v1/users/stats` - 获取用户统计数据

#### 新增实体和Service
- `Favorite` 实体 + `FavoriteRepository`
- `FavoriteService` + `FavoriteController`

## v1.1.0 (2026-07-02)

### ✨ 新增功能

#### 我的发布页面
- 新增"我的发布"页面，展示用户发布的所有帖子
- 支持按类型筛选（全部/信息广场/邻里互助）
- 支持分页加载和下拉刷新
- 点击帖子可跳转到帖子详情页

#### 我的互助页面
- 新增"我的互助"页面，展示用户参与的互助任务
- 支持按角色筛选（全部/我发布的/我帮助的）
- 任务卡片展示互助类型、状态标签、酬金等信息
- 支持分页加载和下拉刷新

#### 设置页面
- 新增"设置"页面，提供基础设置功能
- 消息通知开关（本地存储设置）
- 缓存清理（智能保留登录态和环境配置）
- 环境切换（mock/dev/test/prod，开发调试用）
- 关于邻里圈（版本信息）
- 退出登录（清除Token和用户信息）

#### 静态资源补充
- 新增 TabBar 图标（广场、互助、我的，各2种状态，共6个图标）
- 新增默认头像图片
- 新增空状态占位图

### 🔧 后端新增

#### 新增接口
- `GET /v1/posts/my` - 获取当前用户发布的帖子列表（分页）
- `GET /v1/orders/my` - 获取当前用户参与的互助任务（支持role参数：all/published/helped）
- `GET /v1/orders/{id}` - 获取互助任务详情

#### 后端Service新增
- PostService: 新增 `getMyPosts` 方法
- OrderService: 新增 `getMyOrders` 和 `getOrderDetail` 方法

### 🐛 问题修复
- 修复个人中心"我的发布"、"我的互助"、"设置"菜单点击无响应的问题
- 修复个人中心"帮助与反馈"功能空白的问题
- 修复 TabBar 图标缺失导致导航栏显示异常的问题

## v1.0.1 (2026-07-01)

### ✨ 新增功能

#### 帖子详情与评论
- 新增帖子详情页，支持查看完整帖子内容
- 新增评论功能，支持发表评论、查看评论列表
- 评论支持点赞
- 图片支持点击预览放大

#### 点赞功能
- 帖子支持点赞/取消点赞
- 点赞状态实时同步
- 点赞数实时更新
- 点赞按钮视觉反馈（红心/白心切换）

#### 个人中心
- 新增"我的"页面，底部导航栏第三个Tab
- 个人信息展示（头像、昵称、认证状态）
- 数据统计（发布数、获赞数、评论数）
- 功能菜单（我的发布、我的互助、我的收藏、设置等）
- 认证状态快捷入口

### 🎨 UI/UX 优化

#### 认证引导优化
- 首页顶部新增认证状态提示条（未认证/认证中）
- 点击提示条可直接跳转到认证页
- 未认证用户更清晰的认证引导

#### 时间显示优化
- 时间显示改为相对时间格式
- 支持"刚刚"、"X分钟前"、"X小时前"、"X天前"等
- 超过一个月显示具体日期

#### 发布页优化
- 标题增加字数统计（0/100）
- 与内容字数统计保持一致

### 🔧 后端优化

#### 新增模块
- 评论模块（Comment实体、Service、Controller、Repository）
- 点赞记录模块（PostLike实体、Repository）
- 评论点赞记录（CommentLike表）

#### 数据库更新
- 新增 `comments` 表（评论表）
- 新增 `post_likes` 表（帖子点赞记录表）
- 新增 `comment_likes` 表（评论点赞记录表）
- 新增相关索引
- 新增触发器（自动更新updated_at）

#### 接口更新
- 新增评论列表接口 `GET /v1/comments`
- 新增发表评论接口 `POST /v1/comments`
- 新增删除评论接口 `DELETE /v1/comments/{id}`
- 新增评论点赞接口 `POST /v1/comments/{id}/like`
- 优化帖子点赞接口 `POST /v1/posts/{id}/like`（支持点赞/取消点赞）

#### 缓存优化
- 新增评论列表缓存
- 评论变更自动失效缓存
- Cache Aside策略保持一致

### 📱 前端页面

| 页面 | 路径 | 说明 |
|------|------|------|
| 信息广场 | pages/index/index | 已有，优化认证引导和点赞 |
| 邻里互助 | pages/helper/index | 已有 |
| 个人中心 | pages/profile/index | 新增 |
| 业主认证 | pages/auth/index | 已有 |
| 发布页 | pages/publish/index | 已有，优化字数统计 |

### 🔒 安全与权限

- 所有写操作接口均已接入认证状态拦截器
- 未认证/认证中用户无法发表评论、点赞
- 评论只能删除自己的
- 权限控制严格遵循三态模型

### 🐛 问题修复

- 修复点赞后无视觉反馈问题
- 修复点击帖子跳转到不存在页面的问题
