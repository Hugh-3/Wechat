# 邻里圈 - 版本更新说明

## v1.0.1 (2026-07-01)

### ✨ 新增功能

#### 帖子详情与评论
- 新增帖子详情页，支持查看完整帖子内容
- 新增评论功能，支持发表评论、查看评论列表
- 评论支持点赞
- 图片支持点击预览放大

#### 点赞功能
- 帖子支持点赞/取消点赞
- 点赞状态实时同步
- 点赞数实时更新
- 点赞按钮视觉反馈（红心/白心切换）

#### 个人中心
- 新增"我的"页面，底部导航栏第三个Tab
- 个人信息展示（头像、昵称、认证状态）
- 数据统计（发布数、获赞数、评论数）
- 功能菜单（我的发布、我的互助、我的收藏、设置等）
- 认证状态快捷入口

### 🎨 UI/UX 优化

#### 认证引导优化
- 首页顶部新增认证状态提示条（未认证/认证中）
- 点击提示条可直接跳转到认证页
- 未认证用户更清晰的认证引导

#### 时间显示优化
- 时间显示改为相对时间格式
- 支持"刚刚"、"X分钟前"、"X小时前"、"X天前"等
- 超过一个月显示具体日期

#### 发布页优化
- 标题增加字数统计（0/100）
- 与内容字数统计保持一致

### 🔧 后端优化

#### 新增模块
- 评论模块（Comment实体、Service、Controller、Repository）
- 点赞记录模块（PostLike实体、Repository）
- 评论点赞记录（CommentLike表）

#### 数据库更新
- 新增 `comments` 表（评论表）
- 新增 `post_likes` 表（帖子点赞记录表）
- 新增 `comment_likes` 表（评论点赞记录表）
- 新增相关索引
- 新增触发器（自动更新updated_at）

#### 接口更新
- 新增评论列表接口 `GET /v1/comments`
- 新增发表评论接口 `POST /v1/comments`
- 新增删除评论接口 `DELETE /v1/comments/{id}`
- 新增评论点赞接口 `POST /v1/comments/{id}/like`
- 优化帖子点赞接口 `POST /v1/posts/{id}/like`（支持点赞/取消点赞）

#### 缓存优化
- 新增评论列表缓存
- 评论变更自动失效缓存
- Cache Aside策略保持一致

### 📱 前端页面

| 页面 | 路径 | 说明 |
|------|------|------|
| 信息广场 | pages/index/index | 已有，优化认证引导和点赞 |
| 邻里互助 | pages/helper/index | 已有 |
| 个人中心 | pages/profile/index | 新增 |
| 业主认证 | pages/auth/index | 已有 |
| 发布页 | pages/publish/index | 已有，优化字数统计 |
| 帖子详情 | pages/post-detail/index | 新增 |

### 🔒 安全与权限

- 所有写操作接口均已接入认证状态拦截器
- 未认证/认证中用户无法发表评论、点赞
- 评论只能删除自己的
- 权限控制严格遵循三态模型

### 🐛 问题修复

- 修复点赞后无视觉反馈问题
- 修复点击帖子跳转到不存在页面的问题
- 修复新用户找不到认证入口的问题
- 修复发布页标题缺少字数提示的问题
